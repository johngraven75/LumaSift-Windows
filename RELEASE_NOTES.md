# LumaSift Windows Release Notes

## 0.1.0 — Standalone Repository Bootstrap

### Included

- Public standalone repository with the repository-wide engineering and Total Automation policies.
- Enforced Master Engineering Standard and automated governance check.
- Architecture, security, release, and rollback documentation scaffolding.

### Planned Product Scope

- Exact duplicate proof using sampled candidate hashing followed by full SHA-256 verification.
- File-category selection for videos, MP3 audio, DOCX, PDF, and image files.
- Explainable ranking, live progress, dispositions, quarantine-first resolution, and explicit purge safeguards.

### Distribution Status

This bootstrap does not claim a packaged application release. A windows installer release once the windows hosted packaging workflow succeeds.

### Rollback

The baseline commit may be reverted cleanly before application code and release workflows are introduced. After packaging begins, rollback instructions will name the previous verified tag and its artifact checksums.
